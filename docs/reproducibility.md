# 复现和修订记录

## 数据与原始分析

数据来自天池公开淘宝用户购物行为数据集。保留用户ID模20为0的源记录，正式清洗使用中国时区九天观察窗口。全量100,150,807行及样本4,969,753行来自历史Notebook运行记录；清洗后的4,966,986条在后续复盘中重新聚合。

## 核对范围

`08_project_review/audit_project.py`从本地清洗CSV计算日志总量、行为数、用户和买家数、跨日购买、日均对比、小时分布、首次观测留存及严格路径。它同时对照仓库保存的每日行为和次日回访汇总，并核对历史分群总人数。历史分群仅核对汇总人数，未恢复原规则。

## 发布整理

公开副本清除了Notebook输出、执行计数、数据库密码和项目绝对路径；个人简历、求职训练手册、原始明细、逐人高意向名单和检查点未加入仓库。原始本地项目保留原样。

补充了便于在新目录执行的分块处理脚本、MySQL建表和导入脚本、环境变量示例、依赖范围与指标说明。分块处理不把数据全量读入内存；独立核对脚本仍会读取完整清洗样本。

清除历史Notebook中未能追溯来源的手填漏斗图、手填摘要及相关推断。历史行为覆盖SQL与严格时序漏斗分开命名。第七日回访图的横轴改成活跃队列日期。

## 尚未完成的验证

MySQL建表、导入和查询没有在本次发布环境中连接服务执行；历史可视化Notebook依赖的user_daily_active、final_user_segments等中间表未完整留档。分群规则、策略落地与线上实验结果均不可据此声称已验证。依赖文件使用兼容版本范围，不是带哈希的环境锁定文件。
