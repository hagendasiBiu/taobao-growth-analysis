# 指标定义

分析窗口为北京时间2017年11月25日00:00:00至12月4日00:00:00之前。

| 指标 | 粒度与定义 |
|---|---|
| PV | pv事件数，反复浏览会重复计数 |
| 全行为UV或DAU | 指定时间范围内任意行为的去重用户数 |
| 浏览UV | 指定范围内有pv行为的去重用户数 |
| 购买人数 | 指定范围内有buy行为的去重用户数 |
| 购买次数 | buy事件数，无法仅凭日志还原订单数 |
| 活跃用户购买率 | 购买人数/全行为活跃人数，分子分母时间窗口相同 |
| 跨日购买比例 | 购买日期去重至少2天的用户数/所有买家数，不要求连续两天 |
| 活跃队列次日回访 | D日所有活跃者中D+1日又活跃的人数占比 |
| 首次观测次日留存 | 窗口中首次在D日出现的用户中D+1日活跃的人数占比 |
| 第七日回访 | D日活跃者中D+7当日活跃的比例，不是未来七天任一天回来 |
| 严格用户商品漏斗 | 同一user_id和item_id存在pv时间<收藏或加购时间<buy时间，各阶段按用户商品对计数 |

UV不跨日期直接相加当作多日去重用户；日均DAU需要先按日期去重再平均。

购买事件/PV可以称购买与浏览事件之比，不能不说明就称用户购买转化率。若分母是浏览UV，分子也应取浏览与购买用户的交集。

首次观测日不等于注册日。观察终点之后的数据不可得，应排除无法观察完整后续窗口的队列，而非把它们计为未留存。

漏斗统计的是存在有效顺序的用户商品对，不要求每个买家都走过收藏加购。取各行为全局最早时间后比较，可能漏掉后续有效路径；代码先取最早PV，再寻找其后最早意向，再判断意向后是否买过。同秒事件无法确定顺序，采用严格大于排除。
